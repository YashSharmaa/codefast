# Parallel waves

Next I want to see which steps of a plan could run at the same time. Please add a package that groups the steps of a plan into waves and finds the longest chain of steps, and a command that prints both.

## Interface changes

```go
// new package sched
func Waves(f *parse.File, steps []plan.Step, jobs int) [][]string
func Critical(f *parse.File, steps []plan.Step) []string
```

New command: `waves FILE MTIMES [-j N] [GOAL...]`.

## Waves

The dependencies of a step are those of `f.Resolve(step.Target)`, so targets made from pattern rules have theirs. The steps are placed one at a time, in the order of `steps`. A step goes into the lowest wave number that is higher than the wave of every one of its dependencies that is itself a step, and that holds fewer than `jobs` steps so far when `jobs` is greater than 0. Waves are numbered from 1, so a step with no dependency among the steps goes into wave 1 if there is room. A `jobs` of 0 or less means no limit.

`Waves` returns the waves from 1 to the highest one used, each holding the target names in the order they were placed. With no steps the result is empty (length 0). Example: steps `a`, `b`, `c` (which depends on `a`) and `d`, all without other dependencies, give `[[a b d] [c]]` with no limit and `[[a b] [c d]]` with `jobs` 2.

`Critical` returns the longest chain of steps in which each step depends on the one before it. It is found from the waves without a limit: start with the first name of the last wave, then repeatedly move to the first of its dependencies, in the order of its dependency list, that is in the wave just before, until wave 1 is reached. The names are returned from wave 1 on. With no steps the result is empty (length 0). In the example above it is `[a c]`.

## The command

`waves FILE MTIMES [-j N] [GOAL...]` computes the steps exactly as `plan` does, with the same errors and exit codes, and then prints one line per wave, `wave K: NAMES` with the names joined by one space, for example `wave 1: main.o util.o`, and then one more line, `critical: NAMES`, with the names from `Critical` joined by one space. The critical line does not depend on `-j`. With no step it prints only `nothing to do`. It exits 0. `-j N` is recognised only right after MTIMES. N must be written with digits only and be at least 1. A `-j` without N, or any other N, is a usage error like the others (a line starting with `usage:` on stderr, nothing on stdout, exit 2). Without `-j` there is no limit. `waves` needs at least FILE and MTIMES.
