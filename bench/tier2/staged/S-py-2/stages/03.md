# Scalar functions

Next I want functions in expressions, such as `UPPER(name)` or `ROUND(score, 1)`. Please put them in a new module and call them from queries.

## Interface changes

- New module `csvq/functions.py` with `call_function(name: str, args: list)`. It applies the function called `name` (in any case) to the argument values and returns the result, or raises `QueryError` as described below.
- Grammar: a name without quotes followed by `(` is a function call, `name([expr, ...])`. Function names are case-insensitive and are not keywords, so `upper` alone is still a column name. A quoted name followed by `(` is a `QuerySyntaxError`.

## Rules

- An unknown function, or a wrong number of arguments, is a `QueryError`, raised by `query` even when the tables have no rows.
- Unless the table says otherwise, a `NULL` argument makes the result `NULL`, and an argument of the wrong type is a `QueryError`. Booleans are neither numbers nor strings. An integer argument must be an `int`.
- Calls may appear wherever an expression may, also inside aggregates and around them: `SUM(ABS(x))`, `UPPER(MIN(name))`. With aggregation, a column used in a call outside an aggregate must be a GROUP BY column, as for any expression. A call is named `colN` like any other expression without an alias.

| Function | Result |
|---|---|
| `UPPER(s)`, `LOWER(s)` | the string `s` in upper or lower case, as Python's `str.upper()` and `str.lower()` |
| `LENGTH(s)` | the number of characters of the string `s` |
| `TRIM(s)` | `s` without leading and trailing whitespace, as `str.strip()` |
| `SUBSTR(s, start)`, `SUBSTR(s, start, length)` | the characters of `s` from 1-based position `start` on, at most `length` of them. `start` must be at least 1 and `length` at least 0, else `QueryError`. Past the end of `s` the result is `''` |
| `REPLACE(s, old, new)` | `s` with every `old` replaced by `new`, all three strings. An empty `old` gives `s` unchanged |
| `INSTR(s, sub)` | the 1-based position of the first `sub` in `s`, 0 when there is none, 1 when `sub` is empty |
| `CONCAT(v, ...)` | one or more values of any type joined into one string. `NULL`s are skipped, numbers are written as by Python `str()`, booleans as `true` and `false`. Only `NULL`s give `''` |
| `ABS(n)` | the absolute value of the number `n`, of the same type |
| `ROUND(n)` | the nearest `int`. Halves go away from zero, so `ROUND(2.5)` is 3 and `ROUND(-2.5)` is -3 |
| `ROUND(n, digits)` | a `float` rounded to `digits` decimals, an integer of at least 0 (else `QueryError`). Halves go away from zero |
| `COALESCE(v, ...)` | the first of one or more values that is not `NULL`, else `NULL` |
| `NULLIF(a, b)` | `NULL` when `a = b` gives `True` (by the rules of `=`, so a number with a string is a `QueryError`), else `a` |
