# One error type that says where

Next, rename the error type, and let an error tell which rule key and which file line it is about.

## Interface changes

- `RuleError` is renamed `RecurError` everywhere: in `recur/errors.py`, in the exports of `recur/__init__.py`, and in every module that raises or catches it. It is still a subclass of `ValueError` and still the only error type the package raises on bad input. The name `RuleError` no longer exists, with no alias.
- `RecurError(message: str, key: str | None = None, line: int | None = None)`. `str(error)` is the message, and the attributes `key` and `line` hold the other two arguments.
- Every error the package raised before is now a `RecurError` with `key` and `line` set as below. The command line still prints `error: <message>` and returns 2.

## key

`key` is the upper-case rule key the problem is about:

- an empty or bad value or list item (a number, a range, a date, a weekday code, an ordinal): the key it belongs to. So `FREQ=DAILY;UNTIL=2026-02-30` has key `UNTIL` and `FREQ=MONTHLY;BYDAY=6MO` has key `BYDAY`.
- an unknown key or a key given twice: that key in upper case, so `color=red;freq=daily` has key `COLOR`.
- a missing `FREQ` or an unknown frequency: `FREQ`.
- both `COUNT` and `UNTIL`: `UNTIL`.
- `BYMONTHDAY` with `FREQ=WEEKLY`: `BYMONTHDAY`.
- a `BYDAY` ordinal that the frequency does not allow: `BYDAY`.
- an empty text, an empty part or a part without `=`: `None`.

Errors that are not about a rule have key `None`. This covers `parse_date` called on its own, `expand` without any limit, `between` with `first > last`, a file that cannot be read, and the errors of `load_schedule` that are not about a rule text (see below).

## line

Only `load_schedule` sets `line`. For each error about one line of the file, `line` is that line number, the same N as in the `line N: ` message. An error in the rule text of a `RULE` or `EXRULE` line also keeps the rule's `key`, and a bad date on an `ADD`, `EXCLUDE` or `START` line has key `None`. A text without a `START` line gives line `None`. All other errors have line `None`.
