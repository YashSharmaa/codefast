# Rules in plain English

Next, I want to show rules to people who do not read rule text. Add a module that describes a rule in English, and use it for rules, schedules and schedule files.

## Interface changes

- New module `recur/describe.py` with `describe(rule: Rule) -> str` and `ordinal(n: int) -> str`. `recur/__init__.py` re-exports `describe`.
- `Rule.describe() -> str` returns `describe(self)`.
- `Schedule.describe() -> list[str]`: the description of each rule in the order added, then `except <description>` for each exclusion rule in the order added, then `also on <date>` for each extra date and `except on <date>` for each excluded date, both ascending without duplicates. Dates are written as `YYYY-MM-DD`.
- `dump_schedule(schedule, *, comments: bool = False)`. With `comments=True` it writes a line `# <description>` just before each `RULE` and `EXRULE` line. Without it the output is unchanged.
- New command `describe RULE`: prints the description. New command `explain PATH`: prints the lines of `Schedule.describe()` for the schedule file at PATH. The `format` command takes a flag `--comments` that passes `comments=True`, and still writes the text exactly as it is.

## The description

`ordinal(n)` for n of at least 1 is n followed by `th` when n % 100 is 11, 12 or 13, and otherwise by `st` when the last digit is 1, `nd` when it is 2, `rd` when it is 3, `th` else. So `1st`, `2nd`, `3rd`, `4th`, `11th`, `13th`, `21st`, `22nd`, `101st`, `111th`.

A list is written as `A`, `A and B`, or `A, B and C` (commas, and ` and ` before the last item). `describe` is these pieces in this order, each only when it applies:

1. `every day`, `every week`, `every month` or `every year` when `INTERVAL` is 1, `every other day` (week, month, year) when it is 2, and `every N days` (weeks, months, years) when it is 3 or more.
2. With `BYMONTH`: ` in ` and the list of month names `January` to `December`, ascending.
3. With `BYMONTHDAY`: ` on the ` and the list of days. First the positive values ascending, each as its ordinal, then the negative values ascending, -1 as `last day` and any other -n as `<ordinal(n)> to last day`.
4. With `BYDAY`: ` on ` (but ` when it is ` when `BYMONTHDAY` is given too) and the list of weekdays in the order of `Rule.byday`. A weekday without ordinal is its English name `Monday` to `Sunday`. With ordinal n it is `the <ordinal(n)> Monday`, with -1 `the last Monday`, with any other -n `the <ordinal(n)> to last Monday`.
5. With `COUNT`: `, once` when it is 1, otherwise `, N times`.
6. With `UNTIL`: `, until YYYY-MM-DD`.

Examples:

- `FREQ=WEEKLY;BYDAY=FR,MO` gives `every week on Monday and Friday`
- `FREQ=MONTHLY;INTERVAL=3;BYMONTHDAY=-1,1,-2;COUNT=4` gives `every 3 months on the 1st, 2nd to last day and last day, 4 times`
- `FREQ=YEARLY;BYMONTH=11;BYDAY=4TH;UNTIL=2030-12-31` gives `every year in November on the 4th Thursday, until 2030-12-31`
- `FREQ=MONTHLY;BYMONTHDAY=13;BYDAY=FR` gives `every month on the 13th when it is Friday`
